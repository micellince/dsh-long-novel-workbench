# 写作预设 · 绝对模板（0.6）

预设 = **写作约定**（视角 / 节奏 / 风格 / 禁忌 / 审阅重点 / 人物功能）。
换预设**不会改正文**；它只影响之后新建的 AI 工作单（续写、重写、审阅、扩写的 prompt 里会带上）。

想自己写一个：复制下面整段 → 改字段 → 工作台「设置 → 📚 写作预设 → ＋ 新建」按字段填进去（或在 `presets.json` 里手工加一条）。

```jsonc
{
  // ── 身份 ─────────────────────────────────────────
  "id": "preset-my-own",          // 唯一 id：小写英文/数字/-，不要重复
  "name": "我的预设",              // 界面上显示的名字
  "desc": "一句话说明这个预设适合什么题材", // 显示在预设卡片上

  // ── 规模 ─────────────────────────────────────────
  "genre": "悬疑",                // 题材标签（可空）
  "plannedChapters": 60,          // 计划章数（写作工作单会参考）
  "chapterWords": 3000,           // 每章目标字数
  "totalWords": 180000,           // 全书目标字数（plannedChapters × chapterWords）

  // ── 叙事视角与节奏 ───────────────────────────────
  "pov": "第三人称限知",           // 第一人称限知 / 第三人称限知 / 第三人称全知
  "tense": "过去时",
  "pacing": {
    "openingChapters": 4,          // 开头几章完成入场
    "escalationEvery": 6,          // 每几章升一次压力
    "midpointRatio": 0.5,          // 中点转折在全书的位置（0–1）
    "climaxRatio": 0.9             // 高潮位置（0–1）
  },

  // ── 风格规则（会被拼进 AI 工作单） ────────────────
  "styleRules": [
    "短句为主，少形容词；不解释情绪，只写动作与物件",
    "每章至少一个具体钩子，章末留牵引"
  ],

  // ── 禁忌（AI 写了就要被判 AI 味 / 退回） ──────────
  "taboo": ["套话式总结", "现代网络用语", "Markdown 强调与标题"],

  // ── 审阅重点（四路审阅时优先看什么） ──────────────
  "reviewFocus": ["事实与连续性", "注意力四拍", "去 AI 味", "读者体验"],

  // ── 人物功能（不是人物卡，是「这类角色必须承担什么」） ──
  "characters": {
    "protagonist": "目标明确但有一个致命缺陷；前十章要看见缺陷的代价",
    "antagonist": "压力持续升级，不能只出现一次",
    "supporting": "每人一个功能：给信息 / 制造阻力 / 情感锚点"
  },

  // ── 备注 ─────────────────────────────────────────
  "notes": "自定义预设的验收口径写在这里"
}
```

## 字段口径

| 字段 | 用途 | 可为空 |
|---|---|---|
| `id` | 唯一标识；应用预设时写进 `project.activePresetId` | 否 |
| `name` / `desc` | 设置页卡片展示 | `desc` 可空 |
| `genre` | 题材标签，进工作单「项目行」 | 可空 |
| `plannedChapters` / `chapterWords` / `totalWords` | 规模预期；应用时同步进作品设置 | 建议填 |
| `pov` / `tense` | 叙事视角与时态，写死进工作单 | 可空 |
| `pacing` | 节奏骨架，供 AI 拆章 / 设计注意力四拍 | 可空 |
| `styleRules` | 风格约定，逐条拼进 prompt | 可空数组 |
| `taboo` | 禁忌清单；命中即按 AI 味处理 | 可空数组 |
| `reviewFocus` | 四路审阅的优先项 | 可空数组 |
| `characters` | 人物**功能**要求（不是人物卡内容） | 可空 |
| `notes` | 验收口径 / 作者备注 | 可空 |

## 内置预设（不可删）

| id | 名称 | 适合 |
|---|---|---|
| `preset-classic-long` | 标准长篇方案 | 常规长篇，80 章 × 3000 字 |
| `preset-suspense-cold` | 冷峻悬疑 | 短句、物件推理、克制情绪 |
| `preset-wuxia-historical` | 家国武侠 | 章回体、文白相间、家国与江湖双线 |
| `preset-literary-real` | 文学现实 | 生活流、留白、少解释 |
| `preset-custom` | 自定义模板 | 空模板，从模板起步 |

## 换预设时发生什么

1. 写入 `project.activePresetId`，并把 `plannedChapters` / `chapterWords` / `pov` / `tense` / 风格规则同步到作品设置与 `style`；
2. **不动正文、不动审阅、不动账本**；
3. 之后生成的 AI 工作单会带新预设（旧工作单不会追溯修改）。
